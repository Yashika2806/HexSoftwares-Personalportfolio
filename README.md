## About

This is my personal developer portfolio showcasing my projects, internships, certifications, and skills. Built as a single self-contained HTML file — no frameworks, no build tools, no dependencies.

## Features

- Custom animated cursor
- Loader screen with counter animation
- Scroll-triggered reveal animations
- Infinite skills marquee
- Live project cards with GitHub + demo links
- Embedded Resume & CV (downloadable directly)
- Fully responsive — mobile to desktop
- Zero npm / zero build step
